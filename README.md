# DC Location Viability Heuristic (DC-LVH)

Interactive scoring tool evaluating European countries for AI data centre investment viability across five AHP-weighted dimensions, with a Monte Carlo forward projection module.

**Live tool:** https://kalpsingh16.github.io/dc-lvh-tool/

## About

The DC-LVH scores each country out of 100 using Analytic Hierarchy Process weights across grid stability, structural surplus and arbitrage, storage market maturity, data centre demand growth, and energy policy maturity. Countries are placed into four investment tiers. The forward projection module runs a Monte Carlo simulation over the scoring inputs.
